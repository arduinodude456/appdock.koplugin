# AppDock 7.8.3

## Deutsch

### File Manager
- Der File Manager wurde im Stil von Google Files neu gestaltet.
- Neue Such-Pill zum Durchsuchen von Dateinamen und Pfaden.
- Dashboard mit **Zuletzt verwendet**, Kategorien und Speicher-Aktionen.
- Neue Kategorien für Dokumente, Bilder, Videos, Audio, Apps und Ordner.
- Zweispaltige Oberfläche mit großen Datei-Kacheln und kompakter Browse-Ansicht.
- Datei-Kacheln zeigen verständliche Symbole, Dateinamen und Größen.
- Ordnernavigation, Scrollen und bestehende Öffnenpfade bleiben erhalten.
- KOReader-, NightLua-, MarkUP- und DReader-Übergaben bleiben sicher und unverändert.

### Qualitätssicherung
- Lua-Syntax aller Plugin-Dateien geprüft.
- Keyboard-, AppStore-, Browser-, DApp-, Ordering- und Setup-Assistant-Regressionstests erfolgreich ausgeführt.
- File-Manager-Regressionen prüfen Dateityperkennung, Suche, Kategorien, zuletzt verwendete Dateien und die zweispaltige Oberfläche.

## English

### File Manager
- Redesigned the File Manager in a Google Files-inspired style.
- Added a search pill for matching file names and paths.
- Added a dashboard with **Recently used**, categories, and storage actions.
- Added categories for documents, images, videos, audio, apps, and folders.
- Added a two-column layout with large file tiles and a compact browse view.
- File tiles show semantic icons, file names, and sizes.
- Folder navigation, scrolling, and existing open handlers remain available.
- KOReader, NightLua, MarkUP, and DReader hand-offs remain safe and unchanged.

### Quality assurance
- Lua syntax checked for all plugin files.
- Keyboard, AppStore, Browser, DApp, ordering, and setup-assistant regression tests pass.
- File Manager regressions cover file type detection, search, categories, recent files, and the two-column layout.
