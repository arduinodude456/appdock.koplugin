# AppDock 6.2.1 — Native Dialogs Restored

AppDock 6.2.1 is the stable rollback build with a version number higher than the previous 6.2.0 release, so plugin update checks can install it correctly.

The release keeps KOReader's standard ButtonDialog, InputDialog and InfoMessage implementations. The experimental custom dialog and Grid Editor changes are not included. Only the AppDock-owned Quick Settings tiles contain the compact Android-like switch visuals for Wi-Fi, Night Mode and Power Saving.
