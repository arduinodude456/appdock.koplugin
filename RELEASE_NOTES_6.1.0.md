# AppDock 6.1.0 — Android-like UI

AppDock 6.1.0 replaces the remaining KOReader dialog surfaces used by AppDock with a unified AppDock UI layer designed for eInk devices.

## Highlights

- New Android-like AppDock popup surfaces for menus, settings, input and notifications.
- New custom on-screen keyboard for AppDock text input flows.
- New switch controls for widgets, Store widgets and pinned apps.
- Short two-frame button press feedback with targeted UI refreshes for responsive eInk interaction.
- Shared UI components are also used by the B/W RAW Video file picker and error messages.
- Existing fast-refresh behavior and video playback paths remain unchanged.

## Verification

All AppDock and VideoPlayer Lua files pass Lua 5.1 bytecode syntax validation. The release archive contains the installable `appdock.koplugin/` directory only.
