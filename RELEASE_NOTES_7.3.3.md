# AppDock 7.3.3 — Smooth Motion

## Animationen

- Der Homescreen-Seitenwechsel verwendet acht statt vier Zwischenframes.
- Die Recently-used-Drawer-Animation verwendet sieben statt vier Zwischenframes.
- Der Animations-Takt wurde auf 25 ms verkürzt, damit die Übergänge schneller und flüssiger reagieren.
- Eine symmetrische Ease-in-out-Sinuskurve sorgt für sanftes Anfahren, schnelle Bewegung in der Mitte und sanftes Abbremsen.
- Der abschließende vollständige Refresh gegen E-Ink-Ghosting bleibt erhalten.
