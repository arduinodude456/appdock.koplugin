# AppDock 6.0.9 — Optional Sleep Screen

AppDock 6.0.9 adds one small optional feature: enable **Settings → Other → Sleep screen** to show a simple AppDock screen when KOReader enters sleep instead of the standard KOReader sleep message.

The screen contains only the AppDock name and “Sleeping” on a plain E-Ink-friendly background. It closes automatically when the device resumes. The feature is disabled by default, stored locally, does not change Simple Mode, and does not add any new sleep behavior.

The latest parallel AppDock core adjustments remain included. Lua 5.1 syntax, focused Suspend/Resume and Settings coverage, existing Core and Browser suites, root/package mirror checks and archive validation passed before release.
