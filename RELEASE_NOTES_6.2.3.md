# AppDock 6.2.3 — Keyboard Done Safety and Full Key Layout

AppDock 6.2.3 fixes the Done action in the AppDock-owned search keyboard by committing the query and rebuilding the homescreen without destroying the active keyboard tree from inside its touch callback.

The keyboard is larger and now includes a number row, QWERTY letters, a Shift key with uppercase/lowercase input behavior, punctuation, symbols, backspace, spaces, Clear and Done. Standard KOReader dialogs remain unchanged outside the AppDock-owned homescreen search.
