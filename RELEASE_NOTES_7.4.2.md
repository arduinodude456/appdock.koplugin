# AppDock 7.4.2

## Boot-Fallback

Die PNG-Dateien bleiben im Plugin enthalten. Der Homescreen verwendet beim Start jedoch wieder die bewährten gezeichneten Logos und erzeugt dort keine ImageWidgets mehr. Dadurch ist der kritische Bootpfad unabhängig von der PNG-Dekodierung; das funktionierende Lockscreen-Profilbild bleibt unverändert.
